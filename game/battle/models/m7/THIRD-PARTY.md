# A file here that is not from Chris's repos

`meshopt-decoder.js`, in this folder, is **meshoptimizer's decoder**: a small piece of code that unpacks the packed
models of the creatures from Aethermoor M7, when a page opens. It is not Chris's and not made for this game. It is
the one Aethermoor M7's own tools use (it comes with the three.js package M7 works with); its header says it was built
from meshoptimizer 0.14. One web address was taken out of a comment (this game's builder stops at web addresses);
nothing else was changed.

It may be used here because of its licence, the MIT licence, below. The licence asks that its copyright line and the
licence's words go with every copy.
