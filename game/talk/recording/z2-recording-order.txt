WHAT THIS IS
These are the spoken lines for part 2 ("zone 2") of a small fantasy video game. Every person in the game speaks aloud. Each line below is recorded as its own sound file, in the voice of the person who says it. The game finds each sound by its file name, so the names must be exactly as written here. The lines are British English.

HOW TO MAKE THE FILES
 1. Model: ElevenLabs Eleven v4 (model id eleven_v4).
 2. Returning voices: Io, Kore, Europa, Callisto, the Grey Hat were recorded for an earlier zone. Use the very same voice and settings as before, so each sounds like the same person.
 3. One voice for each speaker. Choose it from the voice note under the speaker’s name, test it with the audition line (do not save the audition as a file), then use that same voice, with the same settings, for every one of that speaker’s lines.
 4. Say exactly the words after "Say:". Do not add, drop or change a word.
 5. Words in [square brackets] are delivery cues (Eleven v4 audio tags), not words to speak. If a cue is spoken aloud by mistake, make the line again without the cue.
 6. "Tone:" says how the line should sound. It is never spoken. If a line comes out in the wrong tone, make it again; you may put a short cue from the tone note in square brackets at its start, such as [dryly] or [gently].
 7. One sound file for each line, named by its file name exactly, for example z2.captain.01.mp3 (lower case, with the dots as shown).
 8. MP3, one channel (mono), 44.1 kHz, 64 kbps (ElevenLabs output format mp3_44100_64). If a file comes out with two channels, mix it down to one.
 9. Silence: no more than a fifth of a second (0.2 s) of silence at the start and at the end of each file. Trim any longer silence.
10. Loudness: the same for every file and every speaker. Normalise each file to about -18 LUFS (integrated), with peaks no higher than -1 dBFS.
11. Packing: one zip for each speaker, named as shown under the speaker (for example z2-io.zip). Inside it: that speaker’s sound files, and a list named like z2-io-list.csv with two columns, file and seconds: each file’s name and its length in seconds, to one decimal place.
12. Check before handing back: 120 files in 10 zips, every file name below present once, and nothing else.

HOW TO SAY THE NAMES
If a name comes out wrong, Eleven v4 reads the International Phonetic Alphabet written between slashes in the text, for example /ˈaɪ.oʊ/ for Io.
