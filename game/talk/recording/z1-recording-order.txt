WHAT THIS IS
These are the spoken lines for the first part ("zone 1") of a small fantasy video game. Every person in the game speaks aloud. Each line below is recorded as its own sound file, in the voice of the person who says it. The game finds each sound by its file name, so the names must be exactly as written here. The lines are British English.

HOW TO MAKE THE FILES
 1. Model: ElevenLabs Eleven v4 (model id eleven_v4).
 2. One voice for each speaker. Choose it from the voice note under the speaker’s name, test it with the audition line (do not save the audition as a file), then use that same voice, with the same settings, for every one of that speaker’s lines.
 3. Say exactly the words after "Say:". Do not add, drop or change a word.
 4. Words in [square brackets] are delivery cues (Eleven v4 audio tags), not words to speak. If a cue is spoken aloud by mistake, make the line again without the cue.
 5. "Tone:" says how the line should sound. It is never spoken. If a line comes out in the wrong tone, make it again; you may put a short cue from the tone note in square brackets at its start, such as [dryly] or [gently].
 6. One sound file for each line, named by its file name exactly, for example z1.odile.03.mp3 (lower case, with the dots as shown).
 7. MP3, one channel (mono), 44.1 kHz, 64 kbps (ElevenLabs output format mp3_44100_64). If a file comes out with two channels, mix it down to one.
 8. Silence: no more than a fifth of a second (0.2 s) of silence at the start and at the end of each file. Trim any longer silence.
 9. Loudness: the same for every file and every speaker. Normalise each file to about -18 LUFS (integrated), with peaks no higher than -1 dBFS.
10. Packing: one zip for each speaker, named as shown under the speaker (for example z1-odile.zip). Inside it: that speaker’s sound files, and a list named like z1-odile-list.csv with two columns, file and seconds: each file’s name and its length in seconds, to one decimal place.
11. Check before handing back: 236 files in 23 zips, every file name below present once, and nothing else.
